Media Player Hierarchy
Consider the following class hierarchy for a media player application. Read each class carefully before answering the parts below. 
public class Media {
    private String title;
    private int duration; // in seconds

    public Media(String title, int duration) {
        this.title = title;
        this.duration = duration;
    }
    public String getTitle() { return title; }
    public int    getDuration() { return duration; }
    public String toString() { return title + " (" + duration + "s)"; }
    public void   play() { System.out.println("Playing: " + title); }
}

public class Song extends Media {
    private String artist;

    public Song(String title, int duration, String artist) {
        super(title, duration);
        this.artist = artist;
    }
    public String getArtist() { return artist; }
    @Override
    public void play() {
        super.play();
        System.out.println("  by " + artist);
    }
}

public class Podcast extends Media {
    private int episodeNumber;

    public Podcast(String title, int duration, int ep) {
        super(title, duration);
        episodeNumber = ep;
    }
    @Override
    public String toString() {
        return "Ep." + episodeNumber + ": " + super.toString();
    }
}

Question 2 · Constructors & Encapsulation · 10 points
Bank Account System
Consider a banking system. A base class Account tracks a balance. A subclass SavingsAccount adds an interest rate. 
public class Account {
    private String owner;
    private double balance;

    public Account(String owner, double initialBalance) {
        this.owner = owner;
        this.balance = initialBalance;
    }
    public String getOwner()   { return owner; }
    public double getBalance() { return balance; }

    public void deposit(double amount) {
        if (amount > 0) balance += amount;
    }
    public boolean withdraw(double amount) {
        if (amount > 0 && amount <= balance) {
            balance -= amount;
            return true;
        }
        return false;
    }
    public String toString() {
        return owner + ": $" + balance;
    }
}
(a) 4 points
Write the complete SavingsAccount class that extends Account. It should:
  • Store a private double interestRate (e.g. 0.05 = 5%)
  • Have a constructor that takes owner, initial balance, and interest rate — using super()
  • Include an applyInterest() method that adds balance * interestRate to the balance (use deposit())
  • Override toString() to return "[Savings] Alice: $1050.0 (5.0%)"
